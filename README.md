Weather App

A simple and modern weather application that fetches real-time weather data based on the user's location. Built using **HTML**, **CSS**, and **JavaScript**, with data from the **OpenWeatherMap API**.

 Features
- Detects user location using Geolocation API
- Displays current temperature, weather condition, humidity, and wind speed
- Clean, responsive UI with modern styling
- Fully client-side (no backend required)

 Technologies Used
- HTML5
- CSS3
- JavaScript (Vanilla)
- OpenWeatherMap API
